# lineup-data

Auto-generated branch. Per-county Digi channel positions scraped monthly from
digi.ro/grila by `.github/workflows/lineups-update.yml` on `main`.

Consumed by the RemoteTV/Zapy iOS app (LineupClient). Do not edit by hand — the
workflow force-pushes this branch on every run. `unmatched-report.json` lists
scraped names that didn't map to an XMLTV id (extend aliases.json to fix).
